# Your projects

SPARKLE CODER creates new project folders here. Each project keeps its source,
saved tasks and file-edit backups together. Existing managed projects are copied
here on the first launch after upgrading; the originals remain as backups.

Your personal project contents are excluded from SPARKLE CODER's Git repository.
Keep this folder and APP_DATA when updating the app. APP_DATA holds connection
settings and the project list; API keys entered in the app remain memory-only.
