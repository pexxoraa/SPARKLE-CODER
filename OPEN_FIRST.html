SPARKLE CODER · PERSONAL EDITION · 0.6.2

Your coding agent.
In your browser.

The agent runs on your computer. Chat, file imports and downloads, a live run monitor, approvals, changes, and checks are all in the browser. You do not need terminal commands for everyday use.

Upgrading? Use Quit app in the old version before opening this updated launcher. Your existing project settings stay on your device.

Extract the complete ZIP

Use Extract all or your computer's archive utility. Keep the app and its accompanying files together; opening files directly inside the ZIP will not work.

Install Python once

If you already have Python 3.11 or newer, skip this step. Otherwise use the installer from python.org, or your Linux software manager. On Windows, include the Python launcher and file associations.

The agent has no third-party runtime packages to install. Tools for the software it builds, such as Node.js or a compiler, are separate.

Your default browser opens automatically. Closing the browser tab leaves the engine running; use Quit app inside the workspace to stop it.

Your projects are in PROJECTS

New projects are saved in SPARKLE-CODER/PROJECTS. Settings are in APP_DATA beside it. Use a writable app folder, such as Documents. Keep both folders when updating the app.

On first launch, older managed projects and saved tasks are copied here; the originals stay as backups. External projects stay where you registered them. Open Device storage → Open PROJECTS folder to find your files.

Save your brief and check setup

Open Project brief in the sidebar. Describe your goal and list what must work, one line per requirement. Each new task keeps a copy. Open Check setup to identify tools and missing setup without running anything. Finding tools does not mean the project passed its tests.

The default simple view keeps the main screen focused. Use the details button or Switch to advanced view for more information. Your requirements and their evidence appear with the result.

If something goes wrong

The app explains what happened, what it means, and what to do next. Choose Try fixing it or Explain this simply. Long error details are optional. What works and what is left shows checks, usage steps and unfinished work.

Try the demo, then connect Nemotron

Click Take it for a test run. It creates a sample calculator, asks to run a command, runs failing tests, and fixes the bug. Responses in this demo are scripted; edits and tests are real.

For real tasks, open Connect Nemotron, enter your NVIDIA API key or local model endpoint, click Test connection, and save. Keys entered here are kept in memory until you quit the engine.

Create or select a project, describe the outcome, and click Run agent. Watch Run monitor for the current action and live output. Review commands and proposed file edits, use Pause or Stop when needed, then inspect Changes and Checks. Project files now provides import, copy, ZIP export, and file download controls.

Desktop scope: this version targets Windows, macOS, and Linux with a modern browser and Python. Its layout adapts to smaller screens, but it is not an Android/iOS app or a remotely hosted service.
